# AGENTS.md — Инструкции для AI-агентов

Этот файл содержит архитектурные правила, дизайн-систему, стек технологий и стандарты разработки для интернет-магазина музыкальных инструментов. Строго следуй этим правилам при генерации любого кода.

## 1. Технологический стек
- **Фреймворк:** Next.js (App Router) + React + TypeScript (`strict: true`).
- **Стилизация и UI:** Tailwind CSS + `shadcn/ui` + `lucide-react` (иконки).
- **База данных:** PostgreSQL (запущена локально в Docker через `docker-compose.yml`).
- **ORM:** Prisma v6 (`@prisma/client`). Синглтон клиента находится в `src/lib/prisma.ts` (или `lib/prisma.ts`).
- **Валидация:** Zod (для всех форм, Server Actions и параметров запроса).
- **Управление состоянием (клиент):** Zustand (корзина гостя с синхронизацией в `localStorage` и модальные окна).
- **Авторизация:** Auth.js (NextAuth) с поддержкой ролей (`USER`, `ADMIN`).

## 2. Дизайн-система и визуальный стиль (Soft Black & Gold)
Все страницы сайта, включая главную, каталог, карточку товара, корзину, профиль и админ-панель, оформляются строго в единой **мягкой темной теме с золотыми акцентами**:

- **Основной фон страниц (`background`):** Мягкий угольно-черный `#0D0D0F` (в Tailwind: `bg-[#0D0D0F]` или `bg-zinc-950`). Не использовать чистый `#000000`, чтобы не перегружать глаза.
- **Поверхности и карточки (`surface / card`):** Темно-графитовый `#161619` (`bg-[#161619]`). Выпадающие меню, модалки и шапка — `#121214` с легким размытием (`backdrop-blur-md`).
- **Золотистые рамки и акценты (`gold accents`):**
  - Базовая тонкая рамка для карточек товаров, бейджей, инпутов и мини-блоков: приглушенное золото `border-[#D4AF37]/30` (или `border-amber-500/30`).
  - При наведении (`hover`) на карточку товара или кнопку рамка подсвечивается ярче: `hover:border-[#D4AF37]` с мягким золотистым свечением (`hover:shadow-[0_0_20px_rgba(212,175,55,0.15)]`).
  - Главные кнопки действия («В корзину», «Оформить заказ»): золотой фон `bg-[#D4AF37]` с темным контрастным текстом `text-[#0D0D0F]` и `font-semibold`, при наведении — `hover:bg-[#E5C158]`.
  - Второстепенные кнопки и теги: прозрачный фон с золотой рамкой `border border-[#D4AF37]/50 text-[#D4AF37] hover:bg-[#D4AF37]/10`.
- **Типографика и текст:**
  - Основной текст и заголовки: мягкий белый `#F4F4F5` (`text-zinc-100`).
  - Второстепенный текст (описания, характеристики, бренд): приглушенный серый `#A1A1AA` (`text-zinc-400`).
  - Цены и важные бейджи (например, «Хит» или «Скидка»): теплый золотой оттенок `#E5C158`.

## 3. Архитектура и правила Next.js
- **Server Components по умолчанию:** Все страницы и компоненты должны быть серверными, если им не требуется интерактивность (`useState`, `useEffect`, обработчики событий браузера).
- **Минимизация `'use client'`:** Выноси клиентскую логику в маленькие листовые компоненты (например, кнопка «В корзину», галерея фото, фильтры).
- **Мутации данных:** Используй **Server Actions** для создания, обновления и удаления данных (добавление в корзину, оформление заказа, CRUD в админке). Всегда валидируй входные данные через `Zod`.
- **Кэширование:** Используй встроенные механизмы кэширования Next.js (`'use cache'`, `revalidatePath`, `revalidateTag`) для списков товаров, категорий и брендов, сбрасывая кэш при изменениях в админ-панели.
- **Фильтрация в каталоге:** Состояние фильтров (категория, бренд, цена, наличие, сортировка) должно храниться в URL (`searchParams`), а не только в локальном стейте.

## 4. База данных и Prisma
- **Схема БД:** Находится в `prisma/schema.prisma`. Основные модели: `User`, `Category`, `Brand`, `Product`, `Cart`, `CartItem`, `Order`, `OrderItem`.
- **Денежные значения:** Поля `price`, `oldPrice`, `totalPrice`, `priceAtPurchase` хранятся в базе как `Int` (целые числа). Никогда не используй `Float` для денег.
- **Характеристики товаров:** Поле `Product.specs` имеет тип `Json?` (JSONB в PostgreSQL) и хранит динамические пары «характеристика — значение» (например, `{"strings": 6, "body": "Ольха"}`).
- **Безопасность заказов:** При создании `OrderItem` обязательно копируй актуальную цену товара в поле `priceAtPurchase`.
- **Сидирование:** Тестовые данные описаны в `prisma/seed.ts` (запуск через `npx prisma db seed`). Не удаляй существующие сиды без необходимости.

## 5. Стандарты кода и TypeScript
- **Типизация:** Запрещено использовать `any`. Используй сгенерированные типы из `@prisma/client` (например, `Prisma.ProductGetPayload<...>`) и типы, выведенные из схем Zod (`z.infer<typeof ...>`).
- **Изображения:** Используй компонент `next/image`. В `next.config.ts` уже разрешен домен `://unsplash.com`.
- **Обработка ошибок:** В Server Actions возвращай структурированный результат (`{ success: boolean, data?: ..., error?: string }`), а не роняй приложение необработанными исключениями.
- **Язык интерфейса:** Весь пользовательский текст (кнопки, заголовки, сообщения об ошибках, плейсхолдеры) пишется на **русском языке**. Названия переменных, функций, файлов и комментарии в коде — на **английском** (или понятном русском в комментариях по согласованию).

## 6. Команды для проверки
Перед завершением крупных задач убедись, что код компилируется без ошибок:
- Проверка типов и сборка: `npm run build`
- Линтинг: `npm run lint`
- Синхронизация схемы БД: `npx prisma db push`
